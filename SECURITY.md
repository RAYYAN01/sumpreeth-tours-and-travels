# Security Policy

## Reporting a vulnerability

Email **info@sumpreethtoursandtravels.com** with details and steps to
reproduce. Please do not open a public issue for security reports.

We aim to acknowledge within 5 working days. Do not run automated scanners
against the production site beyond what is needed to demonstrate an issue, and
do not access, modify or delete data that is not yours.

A machine-readable version of this contact is served at
`/.well-known/security.txt`.

## Supported

The latest deployed version of the site is the only supported version.
